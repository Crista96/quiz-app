# Quiz Application

## Application Idea and Purpose
The Quiz Application is a quiz management application that allows users to create, manage, and answer quiz questions. The application contains a quiz bank where multiple choice questions are stored. Users can play quizzes using questions from the quiz bank and filter questions by category.

Users can also add new questions to the quiz bank. Each question contains multiple answer options and can be assigned to a category, which can later be used to organize or filter quiz questions.

The application records answer attempts and shows statistics related to quiz performance.

## Deployment
The application is deployed online and can be accessed at:

https://crista96.github.io/quiz-app/

## How to Use the Application
1. Open the application in a web browser using the deployment link. From the home page you can navigate to the different views of the application.
2. Use **Play Quiz** to answer questions from the quiz bank.
3. Use **Question Bank** to browse existing questions.
4. Use **Add Question** to create a new multiple choice question and assign it to a category.
5. Use **Stats** to view statistics about answered quiz questions.
